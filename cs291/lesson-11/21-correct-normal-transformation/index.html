我在我 網路上的第一篇文章 寫過這個問題，當時是 1987。

反矩陣和轉置矩陣屬於線性代數的範疇。如果你對這個主題有興趣,可以考慮修習 可汗學院的課程。若想找一本專門針對電腦圖學的書,我很推薦 Farin 和 Hansford 合著的 《Practical Linear Algebra》，這本書透過大量圖示逐步建立直覺。至於為什麼要使用反矩陣的轉置，想看詳細推導以及其他實用數學內容的話，可以參考 Lengyel 的 《Mathematics for 3D Game Programming and Computer Graphics》。

譯註：《3D Math Primer for Graphics and Game Development》 也不錯，可以線上閱覽。
