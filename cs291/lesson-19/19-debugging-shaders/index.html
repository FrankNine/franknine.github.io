譯註：現在 RenderDoc 成為開源專案和大家預設會用的繪圖 API 除錯工具。支援 DirectX、OpenGL、Vulkan 甚至是 Nintendo Switch 專用 NVN。各家繪圖晶片生產廠商也都有推出除錯工具，像是 NVIDIA Nsight、AMD Radeon™ Developer Tool Suite、Intel Graphics Performance Analyzers。手機 GPU 廠商、遊戲主機廠商也都有類似工具，如 PIX，就不一一列舉。

EA 開源了 ShaderToHuman 專案，可以用 Shader 輸出字串等除錯資料到螢幕。概念與這堂課類似，但是更方便，值得研究。
